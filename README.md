# Hi, I'm Eric

**从不会写代码出发，与 AI Agent 一起学习、构建、进化。**

我是一名从业务和创意出发的开发者。我的起点是不会写代码；现在，我把真实问题带给 Agent，一起拆解需求、做出原型、测试和复盘，在一次次迭代中学习开发。

从广告数据分析、客服助手，到定制 Agent 和企业工作流程，我始终关心一件事：**让创意成为用得起来的产品，让思考成为可执行的流程，让方法论帮助别人完成工作。**

## 我正在做什么

我围绕不同业务职能持续构建、试用和迭代，把研究、判断、创作与执行接成一段完整的工作。

- **品牌与定位**：从目标人群、竞品和使用场景中寻找差异，提炼核心卖点、品牌故事与表达规范，让文案和视觉围绕同一个主张。

- **营销与内容**：把市场洞察和产品事实转化为活动策划、跨渠道文案、创意简报、视频分镜与素材，让前期研究真正进入内容制作。

- **销售与商务拓展**：研究潜在客户、创作者和合作伙伴，整理分层依据、个性化提案、跟进准备与商务交接，帮助判断先接触谁、用什么理由、下一步做什么。

- **客户服务与知识**：整理分散的产品和服务资料，让答复能够检索依据、结合上下文起草，并经过人工审核；把反复出现的问题沉淀为知识与评测样本。

- **运营与团队协作**：梳理资料收集、字段核对、任务分工、素材准备、审批、交接和异常处理，让团队看清工作到了哪一步、还缺什么、由谁继续。

- **数据分析与决策**：清洗杂乱报表、统一字段和分析口径，制作广告与经营数据看板、诊断和策略报告，把数据整理成可讨论、可核对的判断依据。

- **产品与交互体验**：把业务需求和创意做成可试用的原型，探索浏览器助手、本地工具、语音交互和学习体验，在实际操作中发现问题并持续调整。

- **Agent 能力与流程工程**：组合知识、工具、Skill 和任务流程，探索定制 Agent 与协作工作台；持续打磨评测、人工审核、权限边界和执行记录。

- **方法沉淀与培训**：把项目中的判断、失败和复盘整理为 Playbook、操作规程、课程、练习与可复用 Skill，让一次探索成为下一次工作能用的经验。

这些方向涵盖原型开发、功能验证和试点探索。这里展示经过抽象的职能、方法与工作产物，不披露客户身份、真实项目名称、内部资料或专属流程。

## 我怎样与 Agent 一起进步

**发现问题 → 说清目标与验收 → 一起构建 → 亲自试用与复盘 → 留下可复用的方法。**

我在学习更准确地提问、更清楚地判断结果，也把反馈写回文档、流程和 Skill，让下一次协作有所积累。对我来说，价值体现在具体的改变里：少一次重复整理，多一份有依据的判断，让一段工作更容易完成。

欢迎交流 Agent 协作、业务产品化，以及从零开始把想法做出来的过程。

- **Methods and training**: turning lessons into playbooks, operating guides, courses, exercises, and reusable skills.
